**Definition 1 (Address Space and Labeled Sets)**

Let $\Sigma := \mathbb{N}^{<\omega}$ denote the set of all finite sequences (words) over $\mathbb{N}$, with empty word $\varepsilon$. For any label set $G$, define the space of addressed elements:


$$\Gamma_G := \Sigma \times G$$


The ambient configuration space is the finite power set:


$$\mathcal{F}_G := \mathcal{P}_{\mathrm{fin}}(\Gamma_G)$$

---

**Definition 2 (Prefixing and Magma Generation)**

For each $i \in \mathbb{N}$, define the address prefix operator $i(-) \colon \mathcal{F}_G \to \mathcal{F}_G$ by:


$$iA := \{(iw, \gamma) \in \Gamma_G \mid (w, \gamma) \in A\}$$

Define the binary grafting operation $\star \colon \mathcal{F}_G \times \mathcal{F}_G \to \mathcal{F}_G$:


$$A \star B := 0A \cup 1B$$

For each generator $\gamma \in G$, define the atomic embedding $[\cdot] \colon G \to \mathcal{F}_G$:


$$[\gamma] := \{(\varepsilon, \gamma)\}$$

The free magma on $G$ is the sub-algebra $M_G \subset \mathcal{F}_G$ generated by the atoms under $\star$:


$$M_G := \langle \{[\gamma] \mid \gamma \in G\} \rangle_\star$$

---

**Proposition 1 (Freeness and Non-Associativity)**

For all $A, B, C \in M_G$:


$$(A \star B) \star C \neq A \star (B \star C)$$

$$A \star B \neq B \star A$$

*Proof.*


$$\operatorname{dom}((A \star B) \star C) = 00\operatorname{dom}(A) \cup 01\operatorname{dom}(B) \cup 1\operatorname{dom}(C)$$

$$\operatorname{dom}(A \star (B \star C)) = 0\operatorname{dom}(A) \cup 10\operatorname{dom}(B) \cup 11\operatorname{dom}(C)$$


Because $0w \neq 00v$ and $1w \neq 11v$ are non-trivial in the free monoid $\Sigma$, the address supports are disjoint.

---

**Definition 3 (Arity Extension / Planar Tree Operad)**

For $n \ge 0$, define the $n$-ary grafting operation $\star_n \colon (\mathcal{F}_G)^n \to \mathcal{F}_G$:


$$\star_n(A_0, A_1, \ldots, A_{n-1}) := \bigcup_{i=0}^{n-1} iA_i$$


with $\star_0() := \emptyset$.

---

**Definition 4 (Profile Projection and Structural Congruence)**

Define the profile projection map $\operatorname{prof} \colon \mathcal{F}_G \to \mathcal{P}_{\mathrm{fin}}(\Sigma)$:


$$\operatorname{prof}(A) := \{w \in \Sigma \mid \exists \gamma \in G, \, (w, \gamma) \in A\} = \operatorname{dom}(A)$$

The congruence relation $\sim$ on $\mathcal{F}_G$ is given by fibers of $\operatorname{prof}$:


$$A \sim B \iff \operatorname{prof}(A) = \operatorname{prof}(B)$$

---

**Definition 5 (Hierarchical Layout Algebra)**

Let $\Omega \subset \Sigma$ be a finite non-empty address profile.

* **Shape:** An element $S \in M_{\mathbb{Z}_{>0}}$ where:

$$S = \{(w, s_w)\}_{w \in \Omega}, \quad s_w \in \mathbb{Z}_{>0}$$


* **Coordinate Space:** The set $\operatorname{Coord}(S) \subset M_{\mathbb{N}}$ of elements $C \sim S$ satisfying pointwise boundary conditions:

$$\operatorname{Coord}(S) := \left\{ C = \{(w, c_w)\}_{w \in \Omega} \;\middle\vert{}\; 0 \le c_w < s_w, \, \forall w \in \Omega \right\}$$


* **Stride:** An element $D \in M_{\mathbb{Z}}$ congruent to $S$:

$$D = \{(w, d_w)\}_{w \in \Omega}, \quad D \sim S$$



---

**Definition 6 (Layout Evaluation Map)**

Given a shape $S$ and stride $D$ sharing profile $\Omega = \operatorname{prof}(S) = \operatorname{prof}(D)$, the layout map $L_{S,D} \colon \operatorname{Coord}(S) \to \mathbb{Z}$ is the canonical inner product:


$$L_{S,D}(C) := \sum_{w \in \Omega} c_w d_w = \langle C, D \rangle$$
